# toddler-timer
This device helps you keep a steady daily routine for your young child. It shows the time, reminds you when tasks are due, and keeps beeping until you mark them done. This is the Arduino IDE code for the project.

What It Does
•	Shows the current date and time on the screen
•	Beeps and shows a message when a task is due
•	Keeps reminding you until you press the # key to mark the task complete
•	Remembers up to 5 daily tasks (even after you turn it off)
•	Lets you add, view, or delete tasks anytime
Everyday Use
Most of the time the screen simply shows the date and time. Leave the device somewhere you can hear it.
When a task is due, the screen changes to show the task name and time, and the buzzer starts beeping. The beeps continue until you press the # key.
Tip: You do not need to do anything special during the day. Just respond when it beeps.
The Keypad
The keypad looks like this:
1	2	3	A
4	5	6	B
7	8	9	C
*	0	#	D

Main buttons you will use:
•	A, B, C, D — open the menus (see next section)
•	# — mark a task as done, or save a name
•	* — go back, cancel, or delete a character
•	Numbers — enter times and type task names
Main Menu
From the clock screen, press one of these keys:
Button	What it does
A	Set the clock (time or date)
B	Add a new task
C	View your saved tasks
D	Delete a task

Tip: Press * at almost any time to go back or cancel.
Setting the Time and Date
Press A from the main screen.
•	Press A again to set the time
•	Press B to set the date
For the time, enter four numbers (HHMM). Example: 0730 for 7:30 AM, or 1430 for 2:30 PM.
For the date, enter eight numbers (MMDDYYYY). Example: 11162026 for November 16, 2026.
Tip: The device keeps time even when unplugged, thanks to its built-in clock battery.
Adding a Task
Press B from the main screen. You can store up to 5 tasks.
Choose a task type:
•	1 — Diaper change
•	2 — Feeding
•	3 — Nap time
•	4 — Bath time
•	5 — Custom name (you type your own)
Then enter the time the same way as setting the clock (four numbers, HHMM).
Tip: If you need the same task more than once a day (for example two feedings), just add it twice with different times and slightly different names.
Typing a Custom Task Name
When you choose option 5, you type the name using the number keys — similar to old cell phones.
Press a number key several times to cycle through letters:
Key	Letters
2	  A B C 2
3	  D E F 3
4	  G H I 4
5	  J K L 5
6	  M N O 6
7	  P Q R S 7
8	  T U V 8
9	  W X Y Z 9
0	  Space
1	  . , ! ? 1

How to type:
•	Press the same key repeatedly to choose the letter you want
•	Wait about 1 second (or press a different key) to lock the letter in
•	The letter you are currently choosing appears in [brackets] on the screen
•	Press * to delete the last letter
•	Press # when you are finished to save the name
Names can be up to 16 characters long.
Viewing Tasks
Press C from the main screen. Each saved task appears one at a time.
•	Press # to see the next task
•	Press * to exit
Deleting a Task
Press D from the main screen, then press the number of the task you want to remove (1 through 5).
Tip: You can see the task numbers by viewing your tasks first (press C).
When a Task Is Due
The screen shows the task name and time, and the buzzer beeps.
•	The device first plays three short beeps
•	Then it keeps beeping every couple of seconds until you respond
•	Press # to mark the task as done for today
After you press #, you will hear a short “finished” sound and see a confirmation message. The task will not beep again until the next day.
Tip: If several tasks are due at the same time, the device shows the earliest one first. After you mark it done, it will show the next one if needed.
Helpful Tips for Parents
•	Place the device where you can easily hear the buzzer but it will not wake a sleeping child if possible
•	Check the time and date after a power outage or if the device has been unplugged for a long time
•	Use short, clear names for tasks so they fit well on the screen
•	You can have up to 5 tasks. Delete ones you no longer need to free up space
•	The device remembers completed tasks for the day, so you will not get the same reminder twice
